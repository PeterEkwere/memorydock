# MemoryDock

MemoryDock is intended to be a reusable memory system that can connect to Grace and future AI agents, independently of any one agent or model.

## Purpose

Explore how agents can retain useful knowledge and experience, retrieve the right information when needed, and apply it reliably to ongoing work.

The areas under study include:

- **Working memory:** the relevant context an agent needs for its current task.
- **Semantic memory:** facts, preferences and knowledge.
- **Episodic memory:** past conversations, events, actions and outcomes.
- **Procedural memory:** reusable methods and lessons from experience.
- **Retrieval:** finding relevant memories and tracing them to their original evidence.
- **Memory management:** corrections, forgetting, retention and controlled sharing between agents, people and projects.

## Current status

**Research and concept stage.** This repository currently records the project's intent only; no memory engine or agent integration has been implemented.

The architecture, storage, interfaces and implementation language remain undecided while we study how a reliable agent memory system should work.
